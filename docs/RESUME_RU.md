# Описание проекта для резюме

## Короткий блок для hh.ru или PDF

**Haircut Studio — сервис онлайн-записи в салон**

Личный учебный проект · Python / Django / PostgreSQL

[Код, скриншоты и инструкция запуска](../README.md)

Веб-приложение с выбором мастера и свободного времени, личным кабинетом,
временным резервом, демонстрационной оплатой и отменой записи.

- Бронирование через транзакции и блокировки PostgreSQL: повторная проверка
  доступности защищает от конфликтов при одновременных запросах.
- Обработка повторных запросов и событий демо-оплаты без дублирования операций;
  автоматическое истечение резерва и полный демо-возврат при допустимой отмене.
- Подтверждение email, восстановление пароля, проверка владельца записи,
  обязательная двухфакторная аутентификация сотрудников; интерфейс RU/EN.
- Опциональный Telegram-бот сотрудников с расписанием и сохранённой очередью
  уведомлений; доступ ограничен разрешёнными Telegram ID.
- 136 автоматических тестов, включая конкурентные запросы к PostgreSQL,
  проверки прав и повторной обработки событий; подготовлен GitHub Actions workflow.

**Стек:** Python, Django, PostgreSQL, Django ORM, django-allauth, HTML, CSS,
JavaScript, Git, Django TestCase / TransactionTestCase.

**Контекст:** проект выполнен в ходе обучения с ИИ-ассистентом. Оплата
демонстрационная; публичное развёртывание и реальные email/Telegram-интеграции
требуют внешней настройки. Это проектный опыт, а не коммерческая работа.

## Если в форме мало места

**Haircut Studio — Python / Django / PostgreSQL.** Сервис записи к мастерам
с резервом времени, демо-оплатой и возвратами, личным кабинетом, RU/EN
и Telegram-модулем сотрудников. Транзакции и блокировки для конкурирующих
бронирований, безопасная повторная обработка запросов, 136 автоматических тестов.
Личный учебный проект с ИИ-поддержкой; код и инструкция запуска доступны в репозитории.

## Формулировка цели

**Начинающий Python / Django разработчик.** Развиваю практику backend-разработки
на проекте сервиса записи: модели данных, бизнес-правила, работа с PostgreSQL,
проверка доступа и автоматические тесты. Ищу первую позицию, где смогу углублять
навыки под руководством команды и участвовать в разработке прикладных сервисов.

Название должности и формулировку цели стоит адаптировать под конкретную вакансию.
Личные данные, образование, языки и предыдущий опыт в этот блок не добавлены:
их нельзя установить из кода проекта.
